# インタビュー記事テンプレート

文章ルール、タイトルの指針、行動経済学テクニックは `.claude/shared/writing-rules.md` を参照する。このファイルには構成と、インタビュー記事だけのルールを書く。

## 記事構成

```markdown
# {タイトル}

{挨拶文。例: 「こんにちは、{所属}の{インタビュアー名}です。今回は{対象者の所属・職種}の{対象者名}さんに、{テーマ}についてお話を伺いました。」}

> {対象者の印象的な一言}

## プロフィール

| 項目 | 内容 |
|---|---|
| 名前 | {名前} |
| 職種・役職 | {職種・役職} |
| チーム | {チーム名} |
| 入社時期 | {入社年月} |

{リード。見出しは付けない。対象者の人物像と記事の結論を2〜3文で紹介する。最初の50文字に核心を入れる。}

## {セクション1: キャリアや入社の経緯}

{入社動機や背景を物語的に描写する。}

「{インタビュー回答の引用}」

{引用を補足する地の文。}

## {セクション2: 仕事内容・専門性}

{担当している仕事や取り組みを紹介する。エンジニアなら技術、PM ならプロダクト、セールスなら顧客との仕事など、職種に合わせる。}

「{インタビュー回答の引用}」

{引用を補足する地の文。}

## {セクション3: チーム・文化}

{チームの雰囲気や働き方を紹介する。}

「{インタビュー回答の引用}」

{引用を補足する地の文。}

## {セクション4: 未来・メッセージ}

{今後の展望と読者へのメッセージで締めくくる。}

「{インタビュー回答の引用}」
```

## インタビュー記事だけのルール

- 各セクションにインタビュー回答の「」引用を最低1つ含める
- 地の文はインタビュアー（書き手）の視点で、対象者を「{名字}さん」と呼ぶ
- 読者（候補者）が入社後の姿をイメージできる具体性を重視する
- 一記事一テーマ: 対象者の魅力を1つの軸（キャリア、仕事、文化など）で貫く
- タイトルには対象者の特徴や記事のハイライトを入れる（例: 「未経験からテックリードへ。3年間の成長の軌跡」）
- 回答にない情報は書かない。プロフィール表の項目が分からない場合は、その行を削る
- `{...}` のプレースホルダーや、テンプレートの説明文をそのまま残さない
